# Архитектура Nexus Data Flow

## Обзор

Nexus Data Flow - это система для автоматизации сбора и обработки заявок с веб-форм. Она позволяет получать данные от пользователей, сохранять их в базе данных и уведомлять команду о новых заявках в режиме реального времени.

## Компоненты

Система состоит из следующих компонентов:

1.  **Фронтенд-скрипт:**
    *   **Технология:** JavaScript.
    *   **Задача:** Интегрируется с существующими формами на веб-сайте. Перехватывает событие отправки формы, собирает данные и отправляет их на бэкенд-сервис.

2.  **Бэкенд-сервис:**
    *   **Технология:** Python (Flask/FastAPI).
    *   **Задачи:**
        *   Принимает данные от фронтенд-скрипта по API.
        *   Валидирует полученные данные.
        *   Сохраняет данные в базу данных PostgreSQL.
        *   Отправляет уведомление в Telegram.
        *   Ведет логирование всех операций.

3.  **База данных:**
    *   **Технология:** PostgreSQL.
    *   **Задача:** Хранение всех полученных заявок. Структура таблицы будет включать поля формы, а также метаданные (например, дата и время получения заявки).

4.  **Система уведомлений:**
    *   **Технология:** Интеграция с Telegram Bot API.
    *   **Задача:** Моментально уведомляет команду о поступлении новой заявки. Сообщение будет содержать ключевую информацию из заявки.

5.  **Логирование:**
    *   **Задача:** Запись всех входящих запросов и результатов их обработки. Это необходимо для аудита и отладки системы. Логи можно хранить в файлах или в отдельной таблице в базе данных.

## Процесс обработки заявки

1.  Пользователь заполняет и отправляет форму на сайте.
2.  JavaScript-скрипт перехватывает отправку, формирует JSON-объект с данными.
3.  Скрипт отправляет POST-запрос на эндпоинт бэкенд-сервиса (например, `/api/submit`).
4.  Бэкенд-сервис получает запрос, валидирует данные.
5.  Данные записываются в таблицу `applications` в базе данных PostgreSQL.
6.  Бэкенд-сервис отправляет сообщение с данными заявки в указанный Telegram-чат через бота.
7.  Результат операции (успех или ошибка) логируется.
8.  Фронтенд-скрипт получает ответ от бэкенда и показывает пользователю сообщение об успешной отправке.
