# Nexus Data Flow

## Обзор

Nexus Data Flow - это система для автоматизации сбора и обработки заявок с веб-форм. Она позволяет получать данные от пользователей, сохранять их в базе данных и уведомлять команду о новых заявках в режиме реального времени через Telegram.

## Архитектура

Система состоит из следующих компонентов:
*   **Фронтенд-скрипт (JavaScript):** Интегрируется с существующими формами на веб-сайте, перехватывает отправку формы, собирает данные и отправляет их на бэкенд-сервис.
*   **Бэкенд-сервис (Python/FastAPI):** Принимает данные по API, валидирует их, сохраняет в базу данных (SQLite для разработки, PostgreSQL для продакшена) и отправляет уведомления в Telegram.
*   **База данных (SQLite/PostgreSQL):** Хранение всех полученных заявок.
*   **Система уведомлений (Telegram Bot API):** Моментально уведомляет команду о поступлении новой заявки.

Подробное описание архитектуры можно найти в [ARCHITECTURE.md](ARCHITECTURE.md).

## Возможности

*   Прием данных из веб-форм.
*   Сохранение заявок в базу данных.
*   Мгновенные уведомления о новых заявках в Telegram.
*   Простая интеграция с любым веб-сайтом.
*   Автоматическая валидация входящих данных.

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd nexus_data_flow
```

### 2. Настройка виртуального окружения и зависимостей

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Конфигурация переменных окружения (`.env`)

Создайте файл `.env` в корневой директории проекта со следующим содержимым:

```
DATABASE_URL="sqlite:///./nexus.db"
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ТЕЛЕГРАМ_БОТА"
TELEGRAM_CHAT_ID="ВАШ_CHAT_ID_ТЕЛЕГРАМ"
```

*   **`DATABASE_URL`**: Строка подключения к базе данных. Для локальной разработки используется SQLite. Для продакшена рекомендуется PostgreSQL (например, `postgresql://user:password@host:port/dbname`).
*   **`TELEGRAM_BOT_TOKEN`**: Токен вашего Telegram-бота, полученный от @BotFather.
*   **`TELEGRAM_CHAT_ID`**: ID чата или пользователя, куда бот будет отправлять уведомления. Как его получить, описано ниже.

#### Как получить `TELEGRAM_CHAT_ID`:

1.  Создайте бота через @BotFather и получите `TELEGRAM_BOT_TOKEN`.
2.  Начните чат с вашим ботом в Telegram (отправьте ему любое сообщение).
3.  Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН_БОТА>/getUpdates` (замените `<ВАШ_ТОКЕН_БОТА>` на ваш токен).
4.  В JSON-ответе найдите `id` внутри объекта `chat`. Это и будет ваш `TELEGRAM_CHAT_ID`.

### 4. Инициализация базы данных

#### Для SQLite (локальная разработка):

Запустите скрипт для создания файла базы данных и таблицы `applications`:

```bash
source venv/bin/activate
python init_db.py
```
Это создаст файл `nexus.db` в корне проекта.

#### Для PostgreSQL (продакшен):

Если вы используете PostgreSQL, вам нужно будет вручную создать базу данных, пользователя и таблицу `applications`. Пример SQL-запроса для создания таблицы:

```sql
CREATE TABLE applications (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL,
    message TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

### 5. Запуск бэкенд-сервиса

```bash
source venv/bin/activate
uvicorn backend.app:app --host 0.0.0.0 --port 8000 --reload
```
Сервис будет доступен по адресу `http://0.0.0.0:8000`. Флаг `--reload` автоматически перезагружает сервер при изменениях в коде.

## Использование фронтенд-скрипта

1.  **Подключите `form-handler.js`** на ваш веб-сайт перед закрывающим тегом `</body>`:

    ```html
    <script src="путь/к/form-handler.js"></script>
    ```
    (Например, если вы разместите его в той же папке, что и HTML-файл, то `<script src="form-handler.js"></script>`).

2.  **Убедитесь, что ваша форма имеет ID `nexus-form`** и поля ввода имеют атрибуты `name`, соответствующие ожидаемым бэкендом (`name`, `email`, `message`):

    ```html
    <form id="nexus-form">
        <label for="name">Имя:</label>
        <input type="text" id="name" name="name" required>

        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>

        <label for="message">Сообщение:</label>
        <textarea id="message" name="message" required></textarea>

        <button type="submit">Отправить</button>
    </form>
    <div id="nexus-response-message"></div> <!-- Контейнер для сообщений -->
    ```

3.  **Для отображения сообщений** об успехе или ошибке, добавьте на страницу элемент с ID `nexus-response-message`.

## Тестирование

### Юнит-тесты бэкенда

Для запуска юнит-тестов бэкенда используйте `pytest`:

```bash
source venv/bin/activate
pytest
```

### Ручное тестирование фронтенда

Откройте файл `frontend/index.html` в браузере (при запущенном бэкенде), заполните форму и отправьте ее. Проверьте сообщения на странице и уведомления в Telegram.

## Развертывание

Для продакшен-развертывания рекомендуется:
*   Использовать PostgreSQL в качестве базы данных.
*   Использовать продакшен-готовый ASGI-сервер, такой как Gunicorn, с Nginx в качестве обратного прокси.
*   Настроить переменные окружения на сервере.
*   Обеспечить HTTPS для API-эндпоинта.
